# WarDogs — Artillery

Калькулятор дальности и азимута артиллерии для **WARDOGS**.

Вставляешь координаты нахождения своей арты или точки миномёта и цели с карты — получаешь метры и градусы (0° — север, 90° — восток). Есть полный и компактный вид, русский и английский.

**На данный момент калькулятор не учитывает наклон арты/миномёта относительно земли.**

## Запуск

1. Открой вкладку **Releases** справа на этой странице (или [последний релиз](../../releases/latest)).
2. Скачай `WarDogsArtillery.exe`.
3. Запусти файл.

Если Windows напишет, что издатель неизвестен: **Подробнее** → **Выполнить в любом случае**.

## Как пользоваться

1. Открываешь карту
2. Находишь своё местонахождение
3. Нажимаешь правой кнопкой и `ОТМЕТИТЬ КООРДИНАТЫ`
4. В открывающем чате выделяешь координаты `CTRL + A` далее копируешь `CTRL + C`
5. Переходишь в окно калькулятора и вставляешь `правой кнопкой мыши в строку координат пушки` так же можно просто нажать и вставить через `CTRL + V`
6. Повторяешь процедуру с координатами цели
7. Смотришь результат и настраиваешь ствол арты/миномёта. Так же можешь нажать `Поверх всех окон` что бы не переключатся между окнами.
8. Стреляешь, далее корректируешь при необходимости
   
## Что умеет

- Просчёт дальности расстояния по формуле: √(ΔX² + ΔY²) × 100 метров
- Просчёт азимута по формуле: atan2(ΔX, ΔY), 0–360°
- Можно вставлять координаты прям из чата с буквами X / Y : `98.43, 110.38`
- Окно поверх игры
- Компактный режим окна, более удобный если поверх всех окон
   
## В планах реализации

1. Просчёт наклона арты/ствола относительно земли
2. Просчёт наклона цели относительно земли
