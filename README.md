# War Dogs — Artillery

Калькулятор дальности и азимута артиллерии для **WARDOGS**.

Вставляешь координаты пушки и цели с карты — получаешь метры и градусы (0° — север, 90° — восток). Есть полный и компактный вид, русский и английский.

## Скачать программу

Python ставить не нужно.

1. Открой вкладку **Releases** справа на этой странице (или [последний релиз](../../releases/latest)).
2. Скачай `WarDogsArtillery.exe`.
3. Запусти файл.

Если Windows напишет, что издатель неизвестен: **Подробнее** → **Выполнить в любом случае**.

## Что умеет

- Дальность: √(ΔX² + ΔY²) × 100 метров
- Азимут: atan2(ΔX, ΔY), 0–360°
- Вставка координат как из чата: `98.43, 110.38`
- Окно поверх игры

## Запуск из исходников

```powershell
python -m pip install -r requirements.txt
python app.py
```
